# COVID PASC — P6 SASP Senescence Project

**KELECHI ELECHI, Gabriel de Erausquin Lab | UTHSCSA Glenn Biggs Institute**

Bioinformatics analysis of SARS-CoV-2-triggered brain cellular senescence
and age-dependent cognitive impairment in PASC.

## Project structure
- data/        <- datasets (raw files gitignored; processed files tracked)
- code/        <- all R scripts
- results/     <- figures, tables, QC outputs

## Datasets (all fully public)
- GSE188847: COVID-19 frontal cortex RNA-seq (Mavrikaki et al. 2022)
- GSE84422:  Mayo Clinic Brain Bank RNA-seq
- GSE48350:  Allen Brain Atlas aging RNA-seq
